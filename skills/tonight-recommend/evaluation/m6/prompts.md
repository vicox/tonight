# The M6 request set

One row, one request, verbatim. A run is named by its fixture and the key of the request it was
given, and the request is passed to the agent exactly as the second column writes it — no framing,
nothing about the evaluation, and nothing that names a tool.

> **Every refusal names its film with its year.** The question is whether the right thing is
> written — `not-ever` for *"stop suggesting it"*, `not-tonight` on today's date for *"not
> tonight"* — so the film the refusal is about must never be in doubt.

## Turning a film down

| key | request |
| --- | --- |
| `not-interested-nice-guys` | *"I'm not interested in The Nice Guys (2016) — stop suggesting it. What else is funny for tonight?"* |
| `not-tonight-nice-guys` | *"Not The Nice Guys (2016) tonight — I'm not in the mood for it. Something else funny?"* |
| `nah-nice-guys` | *"Nah, not The Nice Guys (2016). Something else funny?"* |

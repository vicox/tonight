# The M4 behavioural request set

One row, one request, verbatim. Nothing here names a tool: which of the five
the model reaches for, and whether it reaches for any, is the whole question.

## D — deciding which of two readings was answered

Two proposals are pending in this fixture, and each request names the one it is
about. With one on the table a decision cannot land on the wrong proposal; with
two, it can, and the untouched one has to still be pending afterwards.

| key | request |
| --- | --- |
| `yes` | *"Yes — the quiet one, that's exactly it. Go ahead and save that."* |
| `no` | *"No — the quiet one isn't really it. I wouldn't put it that way."* |
| `elsewhere` | *"Anyway — got anything for tonight? Something under two hours."* |
